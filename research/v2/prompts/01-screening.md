## 执行要求

1. 先确认能够读取目标论文。只有标题或摘要时，仅做初步筛选，明确分析范围；无法读取时说明缺少材料，不编造贡献或实验。
2. 背景是带范围和日期的证据记录，不是真理。检查背景是否适用，不能以缓存里的断言直接否定论文。
3. 分开评价“发表时的创新性”和“今天的阅读价值”。发表后的工作不能用来否定当时的创新。
4. 区分作者主张、论文实际证据、外部证据和自己的推断；重要判断注明章节、图表或来源。

## 输出到 paper.md §1

- 分析范围：全文 / 摘要 / 其他；实际读取了哪些材料。
- 背景版本、资料截止日期及适用范围。
- 作者声称解决的问题。
- 对照表：作者主张、背景证据、论文证据、判断与不确定性。
- Gap 判断：真实且重要 / 真实但适用范围有限 / 在所述条件下已有较充分方案 / 任务设定的实际意义尚不清楚 / 证据不足，暂不能判断。说明理由和可改变判断的证据。
- 去掉包装后的真实贡献，区分发表时与今天。
- 学习价值、研究相关性、证据质量：分别评价。未确定研究方向时，相关性可写“待探索”。
- 决定：A 精读并考虑复现 / B 仔细阅读 / C 快速了解 / D 暂不阅读；附一句理由。

发现背景需要修正时，列出候选修正及证据，保留原快照。不要静默改写背景以迎合论文。
